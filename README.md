# MoveSpot : Starter kit pédagogique

Interface de réservation de cours de sport pour pratiquer JavaScript ES6+ et la manipulation du DOM.
L'interface est prête, ses fonctionnalités dynamiques sont à développer dans `js/app.js`.

## Démarrage
1. Ouvrez ce dossier dans Visual Studio Code.
2. Ouvrez `index.html` dans un navigateur (ou Live Server).
3. Ouvrez la console (`F12`).
4. Travaillez dans `js/app.js`, une étape à la fois.

## Fichiers
```
.
├── index.html          Interface et conteneurs à manipuler
├── js/data.js          Cours, créneaux et emplacements occupés
├── js/app.js           Parcours pédagogique et zones TODO
└── assets/images/      Visuels locaux des cours
```
`data.js` doit rester chargé avant `app.js`.
